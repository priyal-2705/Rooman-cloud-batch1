CI/CD Pipeline Project

Beginner to Intermediate Automated Cloud Project using GitHub, Jenkins, Docker and AWS EC2.

Project Workflow

This project automatically deploys a website whenever new code is pushed to GitHub.

Step 1

Develop Website

Create the website using HTML, CSS and JavaScript on your local computer.

Step 2

Push to GitHub

Commit the project and push the latest code to your GitHub Repository.

Step 3

Jenkins Pipeline

GitHub Webhook automatically triggers the Jenkins Pipeline.

Step 4

Docker Build

Jenkins builds a Docker Image using the Dockerfile.

Step 5

Run Container

Docker starts a new container with the latest application.

Step 6

Deploy on AWS

Deploy the Docker Container to an AWS EC2 Ubuntu Server.

Step 7

Live Website

Access the deployed website using the EC2 Public IP Address.
